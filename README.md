# Vitrine

## Descrição
Sistema de vitrine simples onde usuários podem criar contas e gerenciar produtos. Cada produto possui uma foto, título, descrição e preço. No frontend, há um botão direto para o WhatsApp com uma mensagem personalizada para o produto.

## Funcionalidades
- Cadastro de usuários
- Criação e gerenciamento de produtos
- Integração com WhatsApp para contato direto

## Tecnologias Utilizadas
### Backend
- Node.js
- Express
- TypeScript
- MongoDB (Mongoose)
- JWT para autenticação
- bcrypt para segurança de senhas

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

## Estrutura do Projeto
Este é um monorepo com:
- `backend/`: Servidor e lógica de negócio
- `frontend/`: Interface do usuário
